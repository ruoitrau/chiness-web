## 🚀 Hướng Dẫn Truy Cập Trực Tuyến Qua GitHub Pages

1. **Vào Cài đặt Repo:** Truy cập mục **Settings** > **Pages** trên repository GitHub của bạn.
2. **Chọn nhánh:** Tại mục *Branch*, chọn nhánh `main` (hoặc `master`), thư mục `/ (root)` và nhấn **Save**.
3. **Nhận link website:** Sau khoảng 1-2 phút, GitHub sẽ cấp link dạng:  
   `https://<username>.github.io/<ten-repo>/`
